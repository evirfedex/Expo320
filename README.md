# eVIR BR FedEx - Mobile
App de Vistorias, Reparos e Relatorios dos Veiculos da FedEx


### Versões utilizadas no projeto:
Antes de executar, é necessario pedir/colocar os seguintes arquivos(dados sensiveis) ao proprietario desse repositorio, e coloca-los nas seguintes pastas:
```sh
/eViR/src/navegacao/StackMOCK.ts
/eViR/src/screen/PreencherTipoVeiculo/PreencherTipoVeiculoMOCK.tsx
```

## Exemplo de execução:

App iOS:
```sh
npx expo run:ios
```
